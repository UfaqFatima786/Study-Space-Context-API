# 📚 Study Space – React User Context

A modern and responsive study dashboard built with **React and User Context** to practice global state management, reusable components, and light/dark theme switching.

## ✨ Overview

**Study Space** is a React-based learning project designed to demonstrate how React Context API can share user information and theme preferences across multiple components without prop drilling.

The project features a dashboard-style interface with profile information, navigation, and theme customization, providing hands-on experience with React's component architecture and state management.

## 🚀 Features

- 👤 **User Context:** Share user information across components.
- 🎨 **Theme Context:** Switch between light and dark themes.
- 🧭 **Navigation Sidebar:** Navigate between dashboard sections.
- 🪪 **Profile Section:** Display user profile information.
- ⚙️ **Settings Section:** Access application settings.
- 📊 **Dashboard Layout:** Organize application content in a dashboard interface.
- 🧩 **Reusable Components:** Build modular and maintainable UI components.
- 📱 **Responsive Design:** Designed to provide a better experience across different screen sizes.

## 🛠️ Technologies Used

- **React.js** – Component-based UI development
- **JavaScript (ES6+)** – Application logic
- **React Context API** – Global state management
- **HTML5** – Application structure
- **CSS3** – Styling and layouts
- **Vite** – Development server and build tooling
- **npm** – Package management


## 🎯 Learning Outcomes

Through this project, I practiced:

- Understanding React Context API and global state management.
- Creating and using Context Providers.
- Accessing shared data with `useContext`.
- Managing theme-related state.
- Passing data between components without prop drilling.
- Organizing a React project into reusable components.
- Building a dashboard-style user interface.
